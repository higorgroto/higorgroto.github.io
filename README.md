# Higor Cristian Groto — Portfólio

Portfólio profissional desenvolvido com Astro, TypeScript e TailwindCSS.

## Deploy

O deploy é feito automaticamente via GitHub Actions para o GitHub Pages.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Adicionar Novo Projeto

1. Crie uma pasta em `src/content/projects/nome-do-projeto/`
2. Adicione as imagens e vídeos na pasta
3. Crie o `index.md` com o Front Matter
4. Commit e push — o deploy é automático

## Estrutura do Projeto

```
src/
├── components/     # Componentes Astro
├── content/        # Coleções de conteúdo (projetos)
├── i18n/           # Internacionalização
├── layouts/        # Layouts
├── pages/          # Rotas
├── styles/         # CSS global
└── types/          # Tipos TypeScript
```
